# Iceberg Background Image Setup

## To use your iceberg image as the background:

1. **Save your iceberg image** as `iceberg-bg.jpg` in the `/public` folder
2. **Replace the placeholder file** at `/public/iceberg-bg.jpg` with your actual image
3. **Recommended image specifications:**
   - Format: JPG or PNG
   - Size: 1920x1080 or higher for best quality
   - Optimize for web (compress to reduce file size)
   - The image should show icebergs in deep blue water with a clear sky
