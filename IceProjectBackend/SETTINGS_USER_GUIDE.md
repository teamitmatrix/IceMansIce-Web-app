## Common Scenarios

### Scenario 1: Update Phone Number

**Situation**: Your business gets a new phone line.

**Steps**:
1. Go to Admin → Site Settings
2. Find "Phone Number" field
3. Replace old number with new number
4. Click "Save Changes"
5. Visit landing page - new number appears!

**Before**:
```
Phone (24/7): 407-310-5007
```

**After**:
```
Phone (24/7): 321-555-1234
```

### Scenario 2: Change Business Hours

**Situation**: You change your operating hours for winter season.

**Steps**:
1. Go to Admin → Site Settings
2. Find "Business Hours" field
3. Update the hours
4. Click "Save Changes"

**Before**:
```
Mon-Fri: 6AM-8PM, Sat-Sun: 7AM-6PM
```

**After**:
```
Mon-Fri: 7AM-7PM, Sat-Sun: 8AM-5PM
```

### Scenario 3: Add Social Media Links

**Situation**: You create Instagram and Facebook pages.

**Steps**:
1. Go to Admin → Site Settings
2. Scroll to "Social Media" section
3. Paste your Facebook URL
4. Paste your Instagram URL
5. Click "Save Changes"

**Result**: Social media icons in footer will now be clickable links.

### Scenario 4: Move to New Location

**Situation**: Your business relocates to a new address.

**Steps**:
1. Go to Admin → Site Settings
2. Find "Address" field
3. Clear old address
4. Type new address
5. Click "Save Changes"

**Before**:
```
501 Florida Central Pkwy Unit 521952
Longwood, FL 32750-5153
```

**After**:
```
123 New Street, Suite 100
Orlando, FL 32801
```

## Validation & Error Messages

### Valid Email Required

If you enter an invalid email:

```
Email Address *
┌────────────────────────────────────────┐
│ invalid-email                          │
└────────────────────────────────────────┘
❌ Email is invalid
```

**Fix**: Enter a valid email format (e.g., `name@domain.com`)

### Required Fields

If you clear a required field:

```
Phone Number *
┌────────────────────────────────────────┐
│                                        │ ◄── Empty!
└────────────────────────────────────────┘

```

**Fix**: Fill in the required field before saving.

## Tips & Best Practices

### ✅ DO:
- Update contact info as soon as it changes
- Double-check phone numbers for typos
- Use full addresses (street, city, state, ZIP)
- Test by visiting the landing page after saving
- Keep business hours format consistent
- Use full URLs for social media (https://...)

### ❌ DON'T:
- Leave required fields empty
- Use invalid email formats
- Save without clicking "Save Changes" button
- Forget to verify changes on landing page
- Use placeholder text as actual data

## FAQ

### Q: Do I need to refresh the landing page to see changes?
**A:** Yes, visitors need to refresh or reload the page to see updates. Changes are applied immediately upon save, but browsers cache pages.

### Q: Can I have multiple admins edit settings?
**A:** Yes, any user with the "admin" role can access and edit settings.

### Q: What happens if I delete all the text in a required field?
**A:** The form will show a validation error and prevent you from saving until you fill it in.

### Q: Can I undo changes after saving?
**A:** No automatic undo, but you can manually go back and change it to the previous value.

### Q: How do I know who last updated the settings?
**A:** The system tracks this internally. Admins can see update history in the database.

### Q: Will changing the company name affect login or other features?
**A:** No, the company name is only used for display on the landing page. It doesn't affect authentication or other functionality.
